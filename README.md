# Customer-Support-Analytics
Данный проект посвящен комплексному анализу операционной деятельности службы поддержки клиентов на основе реального датасета (8 297 обращений). В ходе работы была проведена предобработка данных, рассчитаны ключевые KPI поддержки и выявлены узкие места в распределении нагрузки по каналам связи.

Ключевые бизнес-задачи
* Оценить текущую структуру бэклога и процент успешно завершенных тикетов.
* Найти наиболее нагруженные каналы коммуникации и тематики обращений.
* Выявить пиковые дни недели для оптимизации графиков дежурства операторов.

Основные инсайты и выводы
1. **Доминирование WhatsApp:** Более 60% всего трафика поддержки (4,897 обращений) проходит через WhatsApp. При этом **4,024 запроса — это простые "Консультации"**. 
   * *Рекомендация:* Внедрение умного чат-бота в WhatsApp способно автоматизировать до 48% всей входящей нагрузки департамента.
2. **Операционная эффективность:** 88% тикетов успешно закрыты. Ядро из ТОП-10 операторов работает с эффективностью закрытия свыше 98%, удерживая зависшие задачи в пределах 2%.
3. **Пиковые нагрузки:** Анализ временных трендов показал, что **Четверг является самым загруженным днем недели**. 
   * *Рекомендация:* Усилить смены в среду и четверг за счет перераспределения ресурса с более спокойных дней (понедельник, выходные).

Стек технологий
* **Python** (Pandas, Matplotlib, Seaborn) — предобработка данных, парсинг дат, визуализация.
* **SQL** (PostgreSQL / ClickHouse) — агрегация метрик, группировка статусов, расчет операционного КПД.
